# AgentPay x402 Local Reference

This package is a deliberately small local reference, not production
settlement. It deploys the real Factory/Vault contracts and a six-decimal mock
USDC to Anvil, then exposes local HTTP routes for:

- `POST /orders`: create a deterministic Vault and return Payment Required;
- `POST /orders/{orderId}/fund`: mock settlement, independently verify
  funding, activate the Vault, and issue an example signed ticket;
- `POST /orders/{orderId}/finalize`: submit delivery and release, or refund.

The reference proves escrow states and evidence only. It substitutes direct
mock funding and a local Settlement key for Wallet/Module batch redemption and
the stable Authority Controller.

Run the complete release and refund demonstration from the protocol root when
native Foundry is available:

```bash
pnpm x402:reference
```

The runner starts Anvil, compiles contracts, deploys local contracts, exercises
both terminal paths, prints a JSON summary, and stops Anvil. It uses only
public Anvil development keys and must never target a public RPC.

## Docker Foundry

When Foundry is available only through Docker, start Anvil in terminal A:

```bash
sudo docker run --rm --name agentpay-anvil \
  -p 127.0.0.1:8545:8545 \
  --entrypoint anvil \
  ghcr.io/foundry-rs/foundry:latest \
  --host 0.0.0.0 --silent
```

Compile in terminal B from the protocol root:

```bash
sudo docker run --rm \
  --user "$(id -u):$(id -g)" \
  -e HOME=/tmp \
  -v "$PWD/contracts:/workspace" \
  -w /workspace \
  --entrypoint forge \
  ghcr.io/foundry-rs/foundry:latest build

RPC_URL=http://127.0.0.1:8545 pnpm --filter @agentpay/x402-reference start
```

Production implementations replace direct mock funding with Wallet commitment,
native AgentPay binding acceptance, Safe Module redemption, and independent
Base evidence; replace local finalization with the Authority Controller; and
replace in-process maps with transactional storage. CDP remains an optional
`exact` compatibility adapter, not a required redemption backend.
